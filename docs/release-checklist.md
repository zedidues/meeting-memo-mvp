# 릴리즈 체크리스트

## 1. 앱 기본 검증
- 디버그 빌드가 정상 실행된다.
- 릴리즈 빌드가 정상 생성된다.
- 홈, 메모 작성, 상세, 이메일 발송 흐름이 실제 기기에서 동작한다.
- 마이크 권한 허용/거부 흐름이 자연스럽다.

## 2. 백엔드 검증
- `summary` 함수가 정상 응답한다.
- `sendEmail` 함수가 정상 응답한다.
- 환경변수에 실제 API 키가 정확히 설정되어 있다.
- 배포 후 Functions URL을 앱 설정에 반영했다.

## 3. 보안 점검
- 앱 코드와 저장소에 실제 API 키가 포함되어 있지 않다.
- `.env`, `.firebaserc`, 빌드 산출물 등이 버전 관리에서 제외되어 있다.
- 이메일 발신 주소가 실제 서비스 도메인 정책과 일치한다.

## 4. 스토어 제출 자료
- 앱 이름, 짧은 설명, 자세한 설명 초안이 준비되어 있다.
- 앱 아이콘과 스크린샷이 준비되어 있다.
- 개인정보처리방침 URL 또는 문서가 준비되어 있다.
- 데이터 수집/공유 여부를 Play Console 설문에 맞게 정리했다.

## 5. 품질 점검
- 네트워크 실패 시 사용자에게 오류 메시지가 표시된다.
- 요약 실패 시에도 원문 저장은 가능하다.
- 잘못된 이메일 주소는 발송 전에 차단된다.
- 긴 메모 입력 시 UI가 깨지지 않는다.

## 6. 운영 준비
- 장애 대응용 운영 이메일 또는 연락 채널이 있다.
- LLM 사용량과 이메일 사용량을 확인할 수단이 있다.
- 비용 상한 또는 사용량 제한 정책을 정했다.

## 7. 출시 후 확인
- 첫 배포 직후 실제 기기에서 메모 작성부터 이메일 발송까지 재검증한다.
- 오류 로그와 사용자 피드백을 수집할 준비가 되어 있다.
- 필요 시 요약 길이 제한, 재시도 횟수, 비용 보호 로직을 조정한다.
