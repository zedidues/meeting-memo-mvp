# 개인정보처리방침 초안

본 개인정보처리방침은 `Meeting Memo` 앱이 어떤 정보를 처리하는지 설명하기 위한 초안입니다. 실제 배포 전에는 서비스 운영 주체명, 연락처, 시행일, 실제 인프라 정보를 반영해 최종 검토가 필요합니다.

## 1. 수집 및 처리하는 정보
- 음성 입력을 통해 사용자가 말한 회의 내용
- 사용자가 직접 입력하거나 수정한 메모 원문
- 사용자가 생성한 요약 텍스트
- 사용자가 입력한 이메일 주소 또는 기본 이메일 주소
- 앱 사용 중 발생할 수 있는 최소한의 오류 로그 또는 진단 정보

## 2. 정보 이용 목적
- 음성을 텍스트로 변환하여 메모를 작성하기 위해
- 메모 원문을 요약하여 사용자에게 제공하기 위해
- 사용자가 요청한 경우 메모 내용을 이메일로 발송하기 위해
- 서비스 오류를 확인하고 앱 품질을 개선하기 위해

## 3. 정보의 처리 방식
- 메모 원문과 요약은 사용자의 기기 내부 저장소에 저장될 수 있습니다.
- 요약 생성 요청 시 메모 원문 일부 또는 전체가 서버리스 백엔드와 외부 LLM API로 전송될 수 있습니다.
- 이메일 발송 요청 시 수신 이메일 주소, 제목, 원문, 요약이 서버리스 백엔드와 이메일 서비스 제공업체로 전송될 수 있습니다.
- API 키와 같은 비밀 정보는 앱에 저장하지 않고 서버 환경에서만 관리합니다.

## 4. 제3자 제공 및 처리 위탁
- 요약 생성을 위해 외부 LLM API 제공업체를 이용할 수 있습니다.
- 이메일 발송을 위해 외부 이메일 서비스 제공업체를 이용할 수 있습니다.
- 위 서비스 제공업체는 요청 처리에 필요한 범위 내에서만 정보를 처리합니다.

## 5. 보관 및 삭제
- 메모 데이터는 기본적으로 사용자의 기기에 저장됩니다.
- 사용자가 메모를 삭제하는 기능이 제공되는 경우 해당 데이터는 기기에서 삭제됩니다.
- 서버리스 함수는 요청 처리를 위해 일시적으로 데이터를 사용할 수 있으나, 별도 저장 정책이 없다면 장기 보관하지 않는 것을 원칙으로 합니다.

## 6. 이용자의 권리
- 이용자는 앱 내에 저장된 메모와 이메일 정보를 확인할 수 있습니다.
- 이용자는 저장된 메모를 수정하거나 삭제할 수 있습니다.
- 이용자는 앱 사용을 중단하고 관련 데이터를 기기에서 직접 삭제할 수 있습니다.

## 7. 보안 조치
- 외부 API 키는 클라이언트 앱이 아닌 서버 환경 변수로 관리합니다.
- 네트워크 통신은 HTTPS 기반으로 처리하는 것을 원칙으로 합니다.
- 운영 과정에서 접근 제어, 키 관리, 로그 최소화 등 합리적인 보호 조치를 적용합니다.

## 8. 아동의 개인정보
- 본 앱은 만 14세 미만 아동을 주요 대상으로 설계되지 않았습니다.

## 9. 문의처
- 운영자 또는 개인정보 보호 문의 이메일: `your-email@example.com`

## 10. 시행일
- 시행일: `YYYY-MM-DD`

## 배포 전 치환 필요 항목
- 앱/서비스 운영 주체명
- 문의 이메일
- 실제 사용 중인 LLM 서비스명
- 실제 사용 중인 이메일 서비스명
- 시행일
